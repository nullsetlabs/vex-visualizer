# Worlds 2026 archive (Push Back 2025-2026)

Frozen copy of the VEX Visualizer as it was live at vex.nullsetlabs.org/visualizer/
for VEX Worlds 2026 (last data build 2026-05-18). Served at /visualizer/worlds-2026/.

`index.html` is the built page, byte for byte. The files next to it are what built it:
`vex_visualizer_template.html`, `update_data.py`, `fetch_ms_data.py`, and the data in
`teams_data.json` (866 high school teams, from the 2145 Division Predictor spreadsheet)
and `ms_teams_data.json` (586 middle school teams). No workflow touches this folder.
